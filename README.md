## ▸ TOKEN_ECONOMY // the local-first doctrine

> ```
> CLOUD_FRONTIER_LLM   ▓▓▓▓▓▓▓▓▓▓   $$$$ / 1M tokens
> LOCAL_QUANTIZED_SLM  ▓░░░░░░░░░   ~$0.00 / 1M tokens (electricity & vibes)
> ```
>
> - **Route small, escalate smart** — SLMs absorb ~80% of traffic, frontier LLMs handle the 20% that actually needs them
> - **Quantize ruthlessly** — 4-bit GGUF keeps ~99% of quality at ~25% of the memory footprint
> - **Cache semantically** — identical intents should never pay twice
> - **Privacy is a feature** — on-device inference means zero data leaves the machine
